# 程序设计&程序设计实验

## 课程信息

![](https://img.shields.io/badge/考试课-red)![](https://img.shields.io/badge/2+1学分-red)

![平时分](https://img.shields.io/badge/平时分-40%25-brightgreen)![期末理论考试](https://img.shields.io/badge/期末考试-60%25-brightgreen)

- **授课教师**：黄敏
- **学分**：3学分
- **考核方式**：期末笔试 + 机试
- **特点**：编程基础，考核简单

24年秋季学期，课程内容包括了基础数据类型和语法，选择循环结构，数组字符串，函数指针结构体。上课由两节理论课和两节实验课组成。每节课都有雨课堂的选择题（记入总成绩），实验课上就是写作业，实验课期末有考试题，按照完成时间依序给分。考试分为理论和实验，理论包含一些语法规则，就在 PPT 中，实验则是做算法题，难点在于不出bug而不是想出思路，题目都是实验课上做过的套路。

> 个人私货：主要涉及 C 语言本身的语法，并不是编程思想的课。推荐前往文档开始页的友链寻找培养编程思想的网络资源。
