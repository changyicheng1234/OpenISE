### 教材：

- 工程制图/中山大学出版社
- 工程制图习题集/中山大学出版社

推荐选订两本教材，最少也要订习题集，上课练习依赖习题集，并且网上没资源（有也交不了作业）

### 关于内容：

2024年秋季学期，就是工业制图和CAD，内容涵盖点线面之间的投影关系三视图的绘制与识读轴测图、斜投影图、透视图等辅助表达方式，以及AutoCAD的学习。老师只给了Windows系统的安装包，需要自行购买绘图工具。

课程内容繁多，CAD考试比较简单，但是期末理论考试还是要对上述内容比较了解。
